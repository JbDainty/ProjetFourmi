# Ressources et provenance

- `src/components/Botanical.tsx` : dessins originaux produits pour ce projet, aucune illustration copiée ou téléchargée. Cinq groupes de restauration (tige, feuillage, organes floraux, détails, nuances). Ils nécessitent une revue éditoriale botanique avant publication scientifique.
- `assets/pour.wav` : son synthétique original généré à partir d’oscillations et de bruit avec une enveloppe douce ; aucune bibliothèque sonore tierce.
- `public/icon.svg` : dessin original pour l’application Web. Les icônes de soumission aux boutiques restent à préparer.
- Cormorant Garamond : Christian Thalmann, SIL Open Font License 1.1. Notice : `public/licenses/Cormorant-OFL.txt`.
- Ionicons / react-native-vector-icons : MIT. Notice : `public/licenses/Vector-Icons-MIT.txt`.
- `src/data/taxonomy.json` : résultats d’identification nomenclaturale de l’API GBIF avec URL et date de consultation. Aucun visuel GBIF intégré.

Les licences des dépendances JavaScript sont également disponibles dans leurs paquets npm. Ne pas présenter le contrôle nomenclatural comme une validation des dessins ou comme une certification INPN.
