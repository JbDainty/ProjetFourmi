# Le chemin des écosystèmes

La carte `/carte` est une vue fixe : le titre, le cadre ancien et le raccourci « Ma page » restent à l’écran. Seul le paysage situé dans le cadre défile. Le rebond natif et la propagation du défilement Web sont désactivés sur cette zone. Sur écran court en paysage, le bandeau est condensé.

Le chemin serpente du bas vers le haut. Les médaillons portent le numéro de page ; les étoiles en dessous montrent le meilleur résultat enregistré, avec les étoiles manquantes en contour. La page du carnet est verte. Une fleur apparaît près de chaque page achevée, avec une corolle sur les étapes qui terminent une espèce. La première page non achevée termine le parcours : les étapes suivantes ne sont ni dessinées, ni accessibles en défilant. Rejouer une ancienne page ne réduit pas ce périmètre : il se calcule à partir des réussites, indépendamment de la page chargée. La page 100 termine le livre, sans page 101.

Les cinq paysages sont des illustrations originales réalistes vues du dessus : prairie et fleurs sauvages sous une lumière dorée ; canopées sombres, racines et lucioles du sous-bois ; marais turquoise avec eau transparente, roseaux et nénuphars ; rochers alpins, neige et fleurs violettes ; garrigue ocre, oliviers et lavande. L’atlas original généré pour le jeu se trouve dans `art/journey/biomes-atlas.png`, avec sa provenance et son empreinte dans `source.json`. `scripts/generate-journey-art.mjs` prépare les cinq panneaux en PNG 720 × 1800 avec une palette optimisée et des bords transparents qui se recouvrent pour adoucir les raccords. Le fichier source n’est pas chargé par l’application. Les cinq textures gardent les mêmes dimensions et le même budget de mémoire décodée que les anciens dessins simplifiés. Aucun nouveau module natif n’est requis. Les ornements dorés et les médaillons restent vectoriels ; les étoiles disposent d’un petit support de parchemin pour rester lisibles sur tous les terrains. La lumière, les reflets et la brume sont peints dans les textures, sans ajouter de boucle d’animation.

Un papillon et quelques grains de lumière suivent une animation finie de 2,6 secondes à l’arrivée près d’un chemin restauré ou après un déplacement dans le cadre. La transformation et l’opacité utilisent le pilote natif, sans modification des dessins SVG à chaque image. L’effet s’arrête, respecte l’arrière-plan et le réglage « Animations douces ». Le biome du bandeau change en traversant les régions ; le défilement ne sauvegarde rien.

Toucher un médaillon ouvre une fiche botanique avec nom, illustration et étoiles. Fermer la fiche ne modifie pas la partie. Rejouer charge le plateau initial de la page choisie et conserve les gains ; continuer la page en cours conserve exactement les fioles, mouvements, historique et indices acquis. Le passage au jeu utilise le coordinateur de feuillet existant, avec une garde contre les doubles appuis. Les futurs niveaux restent protégés par `unlocked`.

Validation : `tests/journey-map.test.ts` couvre la limite de progression et les positions des cent médaillons. `GAME_TEST_URL=http://localhost:8124/ node --import tsx scripts/journey-map-smoke.ts` couvre huit tailles de téléphone/tablette, portrait et paysage, les cinq biomes, le défilement interne, la fiche, les étoiles, l’annulation, la reprise, la relecture, la collection terminée et l’arrêt des animations. Les tests de feuillet vérifient aussi le nouveau passage par la fiche. Les exports Android/iOS complètent les vérifications Web ; ils ne mesurent pas la fluidité d’un appareil physique.
